# FPS Aim Trainer

## Project Overview

FPS Aim Trainer is a simple shooting practice game developed using Processing in Python Mode. The game is designed to help players practise mouse aiming skills, improve accuracy, and test their reaction speed.

Players have 30 seconds to hit as many targets as possible. The game tracks successful hits, missed shots, and shooting accuracy.

## Features

- Five randomly positioned targets
- Mouse-based shooting and hit detection
- 30-second countdown timer
- Real-time score and accuracy tracking
- Automatic target repositioning after a successful hit
- Custom crosshair and visual hit effects
- Screen shake effects when shooting
- Game over screen with final performance statistics
- Restart function

## Software and Requirements

- Processing 4
- Python Mode for Processing
- A computer with a mouse or trackpad

No external images, sounds, or additional libraries are required.

## How to Run the Game

1. Download the project code from this GitHub repository.
2. Open Processing and select Python Mode.
3. Open the `FPS_Aim_Trainer.pyde` file.
4. Click the Run button to launch the game.
5. Click anywhere on the start screen to begin playing.
6. Click the circular targets to earn points.
7. Try to achieve the highest score within 30 seconds.
8. When the game ends, press **R** to restart.

## Programming Concepts

This project demonstrates several fundamental programming concepts:

- **Variables:** Store scores, missed shots, timing, and game settings.
- **Lists:** Store the positions of multiple targets.
- **Functions:** Organise different parts of the game.
- **Loops:** Manage targets and repeated operations.
- **Conditional Statements:** Control game states and determine successful hits.
- **Randomisation:** Generate new target positions.
- **Mouse Interaction:** Detect clicks and calculate distances.
- **Data Processing:** Calculate shooting accuracy.

## Project Purpose

The purpose of this project is to explore how programming concepts can be combined to create an interactive game. It demonstrates how code can control visual elements, respond to user input, and process gameplay data.
